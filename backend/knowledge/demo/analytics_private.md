# Закрытый процесс команды Analytics

Синтетическая инструкция AI-buddy. Не является внутренним регламентом Авито.

## Доступ к аналитическому стенду

Только участники синтетической команды Analytics согласуют изменения витрины demo_metrics с ответственным аналитиком. Проверочный маркер закрытого документа: ANALYTICS_ONLY_SYNTHETIC. У стажёров Backend доступа к этой инструкции нет.

## Проверка изменений

В этой демонстрационной команде аналитические изменения проверяют на обезличенной тестовой выборке до публикации. Детали не должны попадать в ответы для другой команды. Этот документ нужен для проверки SQL-фильтра доступа и не является настоящим регламентом.

# Настройка Backend окружения

Синтетическая инструкция AI-buddy. Не является внутренним регламентом Авито.

## Подготовка среды

После подтверждения доступа клонируйте только разрешённый репозиторий. Прочитайте его README и установите перечисленные версии языка и зависимостей. Создайте локальное виртуальное окружение для Python и установите зависимости. Для frontend используйте lock-файл и npm ci. Не подключайте локальный прототип к production.

## Проверка запуска

Скопируйте пример переменных окружения и задайте локальные значения. Не коммитьте .env. Поднимите локальную тестовую базу, примените миграции и выполните тесты по README. Если порт занят, сначала выясните процесс-владелец: не останавливайте чужие сервисы. При ошибке сохраните команду, версию среды и обезличенный текст ошибки и обратитесь к наставнику.

## Последовательность первого запуска

Проверьте версии Python и Node.js по README репозитория. Установите зависимости в отдельное окружение, создайте локальный .env из примера и заполните только локальные параметры. Запустите PostgreSQL, примените миграции и заполните синтетические данные, если это предусмотрено проектом. Затем запустите backend и frontend в разных терминалах и проверьте health endpoint. Конкретные команды берите из актуального README проекта.

## Частые затруднения

Ошибка подключения к БД часто связана с незапущенным контейнером, неверным портом или несовпадением реквизитов. Отсутствующее расширение PostgreSQL исправляют установкой расширения, а не удалением базы. Если зависимости не устанавливаются, проверьте поддерживаемую версию языка и доступ к реестру пакетов. Не используйте sudo для установки пакетов внутрь виртуального окружения.

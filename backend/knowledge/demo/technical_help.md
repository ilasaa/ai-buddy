# Технические проблемы и помощь

Синтетическая инструкция AI-buddy. Не является внутренним регламентом Авито.

## Что собрать для диагностики

Запишите команду запуска, версию ОС и языка, ожидаемое поведение и обезличенную ошибку. Проверьте README и доступность локальных зависимостей. Пароли, API-ключи и cookie перед отправкой лога удалите. Не пытайтесь обходить ограничения доступа.

## К кому обращаться

По локальной настройке начните с наставника. По подтверждённой проблеме корпоративного доступа уточните владельца ресурса или технического администратора через наставника. Реальных телефонов и адресов поддержки в синтетическом прототипе нет. Не удаляйте базу или volume ради устранения ошибки запуска.

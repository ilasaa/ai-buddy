# Будущие SDD-спецификации

Здесь можно размещать спецификации AI-чата, RAG и инструментов корпоративных сервисов.
Перед реализацией описывать источники данных, область доступа каждой роли, разрешённые
действия, подтверждения операций, тайм-ауты и тестируемые критерии приёмки.

Сейчас эти интеграции не реализованы. `/assistant`, `/requests`, `/knowledge` — страницы
с информацией о планах. HTTP API отделён от сервисов; будущие инструменты должны вызывать
сервисы с проверенной идентичностью пользователя и серверными проверками прав.

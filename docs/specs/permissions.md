# Политика прав

| Субъект | Просмотр | Изменения |
| --- | --- | --- |
| intern | Собственные заявки, диалоги, черновики и задачи | Подготовка/подтверждение/отмена своих черновиков |
| mentor | Заявки и адаптация закреплённых стажёров той же команды | Jira/Confluence, только если назначен согласующим и связь актуальна |
| manager | Заявки своей команды, если users.id == teams.leader_id | GitLab, только если назначен согласующим и руководит командой |

Backend сверяет users.mentor_id, users.team_id, teams.leader_id, активность и роль.
Самосогласование запрещено. Одна роль без связи в БД полномочий не даёт.
При смене наставника/руководителя старый согласующий не сможет принять решение.
Новый автоматически не назначается — заявка требует ручной операционной маршрутизации,
API переназначения в этом прототипе отсутствует.

Ресурсы jira/confluence/gitlab и read/write разрешены только стажёру Backend · Demo
для BACKEND. Повышенные права admin и произвольные проекты запрещены. Эта явная
ограниченная политика не масштабируется на произвольные реальные команды без доработки.

Документы: public либо team_id пользователя. Проверка до поиска и чтения. Исторический ответ
скрывается при утрате доступа к его источникам. История и черновики всегда ограничены владельцем.
Все изменяющие API проходят общий CSRF middleware. JWT/ключи не передаются LLM.

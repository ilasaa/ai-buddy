# Политика прав

В приложении две роли: `intern` и `mentor`. Стажёр видит собственные планы, цели, задачи, диалоги, вопросы, черновики и заявки. Наставник управляет планами и проверяет задачи только закреплённых стажёров той же команды, ведёт командные OKR, отвечает на обращения и рассматривает назначенные ему заявки.

Backend сверяет `users.mentor_id`, `users.team_id`, активность и роль. Самосогласование запрещено. Одна роль либо запись владельца команды без назначения стажёра полномочий не даёт. Бывшие руководители мигрируют в наставников с сохранением аккаунтов, паролей и истории; неназначенные стажёры им автоматически не раскрываются.

Jira, Confluence и GitLab согласует назначенный наставник. При изменении назначения прежний согласующий не может принять решение. Миграция двух ролей переназначает только ожидающие заявки; API последующего ручного переназначения отсутствует. Завершённые решения сохраняют прежнего автора.

Ресурсы jira/confluence/gitlab и read/write разрешены стажёру Backend · Demo для проекта BACKEND. Admin и произвольные проекты запрещены. Документы public либо своей команды проверяются до поиска. История диалогов и черновики ограничены владельцем. Все изменяющие API проходят CSRF middleware. JWT и ключи не передаются LLM.

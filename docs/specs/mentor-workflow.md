# Кабинет наставника и руководителя

GET /mentor/overview возвращает только закреплённых стажёров той же команды (mentor)
либо стажёров команды фактического руководителя (manager). Для каждого вызывается существующий
onboarding.overview: завершённые/все задачи, процент и список задач. UI показывает три следующие.

Счётчики requests/pending/approved/rejected вычисляются из видимых реальных записей заявок;
процент задач — completed / total, при отсутствии задач 0. Все люди и исходные задачи демо
синтетические. Это не измерение эффективности внедрения в Авито.

Наставник открывает «Заявки», видит только разрешённые записи, читает историю, добавляет
комментарий и нажимает «Согласовать»/«Отклонить». Второе подтверждение выполняет API.
При параллельном решении блокировка строки позволяет только один переход; второй получает 409.
Статусы и счётчики обновляются после действий и каждые 10 секунд.

Эскалация вопроса наставнику: **не реализована**. Нет MentorQuestion, отправки и кабинета
обращений. При конфликте AI-buddy предлагает уточнить у наставника самостоятельно.
Это явная следующая задача; интерфейс не сообщает о якобы отправленном вопросе.

# Кабинет наставника

GET `/mentor/overview` и `/adaptation/interns` возвращают только закреплённых стажёров той же команды. Отдельной роли руководителя нет. Наставник в `/onboarding` создаёт и меняет план, цели и задачи, согласует ожидания со стажёром, задаёт OKR и проверяет результаты. Существенная правка согласованного плана требует новой версии.

Обычная задача стажёра проходит кнопки «Приступить» → «Завершить». Практическая — отправку результата, решение наставника, при необходимости доработку. Мини-тест — серверную проверку ключа. Задача типа `request` завершается после фактического создания заявки с подходящим ресурсом, без объявления доступа выданным.

Наставник видит обращения стажёра и отвечает через форму; вопросы и ответы хранятся в MentorQuestion. Он согласует Jira, Confluence и GitLab только при актуальном назначении согласующим. Повторное решение по рассмотренной заявке запрещено.

Счётчики и прогресс вычисляются по реальным записям PostgreSQL. Активность чата и синтетические данные не являются доказательством эффекта продукта. Подробные состояния и проверки описаны в [две роли и действия](two-roles-and-task-actions.md).

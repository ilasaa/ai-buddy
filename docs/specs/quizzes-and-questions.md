# Мини-тесты и обращения наставнику

## Мини-тест

Участники: стажёр, руководитель, backend. Предусловие: руководитель назначил задаче тип `quiz` и существующий синтетический тест. Авторы прототипа подготовили Code Review, Git workflow и доступы: по 3 вопроса, проходной порог 2. Вопросы, варианты, ключи и объяснения сохраняются в `knowledge_quizzes`; LLM не участвует в оценке.

1. Стажёр открывает задачу. GET `/quizzes/tasks/{id}` проверяет владельца и тип.
2. Браузер получает текст вопросов, варианты, порог и историю своих попыток; правильные ответы и объяснения до попытки не выдаются.
3. POST передаёт по одному индексу ответа на вопрос. Backend проверяет длину и границы значений.
4. Backend сверяет ответы с сохранённым ключом и сохраняет `QuizAttempt`: пользователь, задача, тест, ответы, балл, результат, объяснения и время.
5. При достижении порога задача становится `done`, сохраняется `TaskVerification`. При неуспехе остаётся незавершённой, стажёр может повторить попытку.

404 — чужая задача/не тот тип; 422 — неполные или неверные ответы; 409 — тест уже пройден. Обычный PATCH и отправка произвольного текстового результата не обходят тест. Гонка двух успешных ответов сериализуется блокировкой задачи. История сохраняется после перезагрузки. Критерий успеха: сервер фиксирует две неуспешную/успешную попытки и только подтверждённый результат изменяет прогресс.

## Обращение

Участники: стажёр и назначенный наставник. Предусловие: активный наставник той же команды. Стажёр в «Моя адаптация» явно отправляет вопрос. Backend берёт наставника из назначения пользователя и сохраняет `MentorQuestion`; LLM не отправляет вопрос от имени стажёра. Повтор одного и того же ещё не рассмотренного вопроса возвращает существующую запись.

Назначенный наставник видит обращение в карточке стажёра, отвечает через форму. Ответ фиксирует автора и время; повторное изменение уже данного ответа запрещено. Руководитель видит состояние обращений своей команды, но не подменяет ответ наставника. Чужая команда и неназначенный наставник не могут читать или отвечать. При отсутствии наставника — 409 с предложением обратиться к руководителю.

Это внутренние записи приложения: внешних сообщений и рассылок нет. При противоречивых инструкциях чат показывает расхождение; стажёр может передать сформулированный вопрос через эту форму. Автоматическое извлечение и отправка вопроса из чата не реализованы.

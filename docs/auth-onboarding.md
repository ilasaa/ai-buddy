# Аутентификация и адаптация

- Argon2 через pwdlib, HS256 JWT через PyJWT с обязательными `sub`, `iat`, `exp`.
- JWT_SECRET приходит из окружения или корневого `.env`; меньше 32 символов — 503 при входе.
- Cookie `ai_buddy_session`: HttpOnly, SameSite=Lax, Path=/, Max-Age=SESSION_MINUTES*60.
  На HTTPS обязательно COOKIE_SECURE=true. Токен не возвращается в JSON и не хранится в Web Storage.
- Каждый POST/PATCH требует точный Origin из ALLOWED_ORIGINS и `X-Requested-With: AI-buddy`.
  Чужой Origin, отсутствие Origin/заголовка — 403, включая login и logout. Кастомный заголовок
  вызывает CORS preflight для междоменных запросов. GET не меняет данные.
- В dev Vite проксирует `/api` в FastAPI, убирая префикс. Origin сохраняется.
  В production reverse proxy должен проксировать `/api` аналогично, отдавать SPA fallback
  для frontend-маршрутов, сохранять Origin и использовать HTTPS. Укажите точный frontend Origin.
- Logout удаляет cookie и очищает клиентский кэш. JWT остаётся криптографически действительным
  до истечения TTL: централизованный отзыв украденных токенов / список сессий пока не реализован.
- В каждой сессии пользователь перечитывается из БД. Неактивный/удалённый пользователь — 401.
  Ошибочный логин — 401; правильный пароль отключённого аккаунта — 403.
  Аккаунты старых записей с password_hash=NULL не могут войти.
- `/auth/me` содержит собственный профиль и назначенного наставника только с ролью mentor
  в той же команде. Email наставника, пароли и персональные данные других стажёров не выдаются.
- `/teams` выдаёт только собственную команду. Для неизвестной/чужой команды одинаковый 404.
  Старый endpoint сохранён, публичная выдача команд закрыта намеренно.
- `/users/me/onboarding` доступен только intern. Идентификатор берётся из сессии.
  Чужая/отсутствующая задача — одинаковый 404. Поле user_id в PATCH запрещено схемой.
- В этой версии все задачи являются самостоятельными задачами стажёра: владелец с ролью intern
  может менять любой из трёх статусов. Подтверждение наставника и типы задач пока не введены.
- Процент = round(done/total*100), для пустого списка 0. При done выставляется completed_at,
  при возврате в работу очищается. Повторный PATCH done сохраняет исходную дату завершения.
  CHECK-ограничения в PostgreSQL дополнительно защищают статусы и completed_at.
- Будущие production-задачи: ограничение частоты входа на gateway, журнал аудита без паролей,
  централизованный отзыв сессий, reset паролей, корпоративный SSO и мониторинг.

Документация библиотек: [FastAPI + Argon2](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/),
[PyJWT](https://pyjwt.readthedocs.io/en/latest/api.html).

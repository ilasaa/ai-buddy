После пересоздания объектов обновлена устаревшая метаинформация collation БД под фактическую libc PostgreSQL-контейнера.

## Границы проверки

- Полная новая Docker-сборка и перезапуск Compose не выполнялись: Docker socket недоступен пользователю, `sudo` требует интерактивной аутентификации. Проверен уже работающий сервис через Nginx и напрямую доступная PostgreSQL 17.11.
- В работающем развёртывании cookie имеет флаг `Secure`. HTTP-клиент httpx не отправляет её автоматически по HTTP; в проверке существующего развёртывания тестовая cookie явно передана в заголовке без вывода токена. На отдельном HTTP-сервисе проверен обычный цикл cookie с `COOKIE_SECURE=false`. Для локального HTTP README предписывает `COOKIE_SECURE=false`; для HTTPS — `true`. Существующая конфигурация HTTPS не изменялась.
- Визуальный браузерный E2E и мобильные экраны в этой проверке не проверялись. Интерфейс покрыт компонентными тестами jsdom и сборкой.
- Реальные запросы к LLM и настоящим корпоративным системам не выполнялись. Jira/Confluence/GitLab остаются демонстрационными адаптерами.
- Ruff проверен для прикладного кода, скриптов и тестов. Полная проверка старых миграций выявляет прежние замечания к импортам и аннотациям; исторические миграции не переписывались.

## Ветки

Содержимое готовой версии взято из `develop`; старые изменения `main` не подмешиваются обратно в реализацию. История `main` сохраняется через merge с выбором дерева `develop`, затем `main` обновляется обычным fast-forward. Итоговые `main` и `develop` должны указывать на один коммит. Force push не требуется.

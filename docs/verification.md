## Сквозной сценарий в Chromium

Проверен реальный HTTP-путь: React → Vite /api proxy → FastAPI → PostgreSQL ai_buddy_test.
Для временного сервера использованы POSTGRES_DB=ai_buddy_test и отдельный случайный JWT_SECRET.
Синтетический seed выполнен именно в тестовой БД; основная БД в браузерном тесте не использовалась.

Проверено:

1. Приватный маршрут перенаправляет на вход. Ошибочный пароль показывает ошибку.
2. Вход стажёра показывает имя, команду, наставника и начальный прогресс 43%.
3. Изменение задачи GitLab на done обновляет прогресс до 57%.
4. После перезагрузки страницы статус сохраняется; возврат в in_progress возвращает 43%.
5. Cookie имеет HttpOnly и SameSite=Lax; localStorage и sessionStorage пусты.
6. Мобильное меню работает при ширине 390px; горизонтального переполнения нет.
7. После выхода приватный маршрут снова открывает вход, /auth/me возвращает 401.
8. Вход наставника и руководителя показывает соответствующую роль;
   /users/me/onboarding для каждой роли возвращает 403.
9. Ошибок JavaScript (pageerror) не обнаружено.
